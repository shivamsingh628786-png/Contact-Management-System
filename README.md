# Contact Management System

## Project Description
A Java-based Contact Management System developed using Java, JDBC, and MySQL. This project allows users to store, manage, search, update, and delete contact information.

## Technologies Used
- Java
- JDBC
- MySQL
- Maven
- Eclipse IDE

## Features
1. Add New Contact
2. View All Contacts
3. Search Contact
4. Update Contact
5. Delete Contact
6. Exit Application

## Database
Database Name: contact_management_db

Table Name: contacts

Columns:
- id
- name
- phone
- email

## How to Run
1. Install Java JDK and MySQL.
2. Open the project in Eclipse IDE.
3. Create the MySQL database and contacts table.
4. Configure database credentials in DBConnection.java.
5. Run Main.java.
6. Select an option from the console menu.
